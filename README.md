# Guheyo Discord Alert Bot

## 📖 설명
구해요(guheyo.com)의 새로운 거래 및 커스텀 키보드 관련 게시글을 모니터링하여, 사용자가 등록한 특정 키워드와 일치하는 게시글이 등록되거나 끌어올려질 때(bumpedAt 기준) Discord로 실시간 알림을 전송해 주는 봇입니다. 디스코드 슬래시 커맨드를 통해 간편하게 키워드를 등록하고 관리할 수 있습니다.

## 🛠️ 사용된 기술 스택
- **언어**: Python 3
- **디스코드 라이브러리**: `discord.py`
- **데이터베이스**: SQLite (사용자 키워드 저장 및 중복 알림 모니터링 방지)
- **웹 스크래퍼**: `requests`, GraphQL API (정규표현식을 활용한 경량화된 파싱)

## 🗂️ 구조
이 프로젝트는 주로 세 개의 핵심 모듈로 구성되어 있습니다.

- `bot.py`: 
  디스코드 봇의 메인 진입점(Entry Point)입니다. 봇의 이벤트 캐치, 슬래시 커맨드(`/알림추가`, `/알림제거`, `/키워드목록`, `/키워드전체삭제`)를 처리하며 지정된 주기마다 데이터를 확인하고 디스코드 채널에 메시지를 전송하는 Background Task 루프가 정의되어 있습니다.

- `database.py`: 
  SQLite3 기반의 데이터베이스 처리를 담당합니다. 사용자별 등록된 키워드를 추가, 제거, 조회하는 기능과 함께 이미 알림이 전송된 게시글(게시글 ID 또는 URL 기준)을 로깅하여 동일한 알림이 중복 전송되는 것을 방지합니다.

- `scraper.py`: 
  guheyo.com 서버와 통신하는 역할을 담당합니다. GraphQL 쿼리를 이용하여 최신 게시글 목록을 불러오고, BeautifulSoup과 같은 외부 파서 없이 정규표현식(Regex)을 이용해 가볍고 빠르게 필요한 제목 및 링크 등의 메타 데이터를 추출합니다.
